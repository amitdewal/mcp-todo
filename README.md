# MCP To-Do

A Model Context Protocol (MCP) server for task and to-do management built with Java and Spring Boot.

---

## Prerequisites

Ensure you have the following installed and configured:

* **Java 21** or later
* **Maven 3.8+**
* An active **OpenAI API Key**
